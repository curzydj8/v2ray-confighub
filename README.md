# 免费节点 hub · v2ray-confighub

每日自动搜集全网公开免费节点订阅，整理去重，按日期归档。

🌐 在线：https://curzydj8.github.io/v2ray-confighub/

## 规则

- 每日新建一个页面，左侧日期栏从上到下、新日期在最上，点击进入当天节点
- txt 订阅链接：把完整链接直接贴到当日页面
- 网页直接展示节点的源：自动保存为 txt 存到项目 `nodes/日期/`，并把本站链接贴到页面
- 全网自动去重：不同网址但 txt 内容完全相同的订阅只保留一份（按内容哈希识别，重复来源会标注出来）

## 数据

- `data/YYYY-MM-DD.json`：当日订阅源列表（名称/链接/节点数/内容指纹/本地存档）
- `data/index.json`：日期索引（新在前）
- `nodes/YYYY-MM-DD/*.txt`：当日各源原始订阅内容快照（可直接作为订阅链接使用）

## 抓取

`fetch_nodes.py`（纯标准库），每日 07:30（北京时间）cron 自动运行。

## 免责

节点来源于网络公开分享，仅供学习交流，请勿用于非法用途。免费节点可用性不稳定。
